# Maratón 6h

App web (PWA) personal para preparar una maratón en 6 horas con un plan andar-trotar de 42 bloques (168 sesiones) que avanza sesión a sesión.

- Plan pensado para 4 sesiones por semana (las extra también cuentan), con intervalos guiados por voz, pitidos y vibración.
- GPS: ruta, distancia, ritmo actual y medio, calorías estimadas.
- Avisos de ritmo: "afloja", "aprieta", "aguanta".
- Historial, registro de peso y copia de seguridad. Los datos se guardan solo en el dispositivo.
- Funciona sin conexión una vez instalada (el mapa del historial necesita internet).

## Publicar

Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Instalar en Android

Abrir la URL de GitHub Pages en Chrome → menú ⋮ → "Añadir a pantalla de inicio" / "Instalar aplicación".

## Limitación conocida

Con la pantalla apagada el navegador corta el GPS. La app mantiene la pantalla encendida durante la sesión y tiene un bloqueo táctil para llevar el móvil en el bolsillo o brazalete.
